# DOGEAT-WISE フード成分換算ツール

犬用フードの保証成分値を、乾物換算（DM%）と 1,000kcal あたりの量へ即時換算する、スマホ優先の静的Webアプリです。フードの適否判断や愛犬の個体情報は扱いません。

## 起動方法

依存関係やビルドは不要です。`index.html` をブラウザで開くだけで使えます。

ローカルサーバーで起動する場合（Python がある環境）:

```powershell
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

## 使い方

1. 水分（%）と代謝エネルギー（ME）を入力し、MEの単位を選びます。
2. 分かる保証成分値だけを入力します。換算結果は入力中に更新されます。
3. 必要なら「成分を追加」または「その他の成分」で任意成分を加えます。
4. 「別のフードを追加」で2つ以上登録すると、「比較する」から成分ごとのDM%と1,000kcalあたりの量を並べて確認できます。

## 計算式

- 乾物換算（DM%）: `表示値% ÷ (100 − 水分%) × 100`
- MEが `kcal/100g`: `栄養素% × 1,000 ÷ ME = g/1,000kcal`
- MEが `kcal/kg`: `栄養素% × 10,000 ÷ ME = g/1,000kcal`

計算結果が1g未満の場合は、同じ値を見やすく `mg/1,000kcal`（1g = 1,000mg）で表示します。

> 表示値は入力された保証成分値・水分値・MEをもとにした参考換算値です。製品中の栄養素の実測値を示すものではありません。

## 基準値との参考比較（2026-09更新）

各フードの換算結果でFEDIAF 2025（成犬・維持期の95/110条件）を選択できます。
比較対象は粗たんぱく質・粗脂肪・カルシウム・リン・ナトリウムの5項目。
最低推奨濃度と換算値を並記し、不足・過剰・適合・個別の必要量は判定しません。
AAFCOは以前の引用資料が改訂案だったため、最新確定資料を検証するまで比較を無効にしています。
出典・条件・保証値の限界は画面内の「基準値の読み方・計算式・出典」を参照。

文字は原則4px拡大（本文15→19px、注釈は最低15px）。スマートフォンでは結果を縦に並べます。
`standards.js` に出典ごとの値を保存、`readability.css` に拡大表示を分離しています。

動作検証：Node.jsとPlaywright導入済みの環境で `node test-ui.cjs`。

## 入力範囲

- 水分: 0%以上、100%未満
- ME: 0より大きい数値
- 成分値: 0〜100%
